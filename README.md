
# Repolyzer

Repolyzer analyzes GitHub repositories and uses AI to generate a project report or a blog.

## Features

- Analyze GitHub repositories
- Generate AI-powered reports or blogs

## Getting Started

```bash
git clone https://github.com/Ruchita1010/Repolyzer.git
cd Repolyzer
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js
- TypeScript
